### 1.2 chart 请求 schema（src/lib/chart/schema.ts，changelog v1.2 仿排除已选 v1.1 格式）

superRefine 规则（冻结文案，逐字）：
- 草案存在且不含指定字 → `名字草案须含指定字「X」`
- 名字形式==='单名' 且 位置==='第二' → `单名仅一位名部，指定字位置不能为「第二」`
- 辈字存在且 位置!=='任一' 且 位置与辈字.位置同（'第一'↔1、'第二'↔2）且 字!==辈字.字 → `指定字与辈字同位且不同字，约束冲突`
- **不加**「仅双名」限制（单名+任一/第一 合法）。

### 1.4 池算法（pool.ts）

抽工厂替换辈字内联字面量（pool.ts:294-299）：

```ts
const lockPool = (c: CharInfo, 计入命中: boolean): SidePools => ({
  命中: new Map([[c.康熙笔画, 计入命中 ? [c] : []]]),
  未命中: new Map([[c.康熙笔画, 计入命中 ? [] : [c]]]),
  全量: new Map([[c.康熙笔画, [c]]]),
  字数: 1,
});
```

**命中归属（修复辈字旧路径的静默放宽，本功能新口径）**：
`计入命中 = 形式==='单名' || 喜用神.size===0 || 喜用神.has(zd.五行)`。
原理（enumeratePairs 双名分支 :182-183）：锁定字落命中表→自由侧取全量（规则由锁定字本身满足）；落未命中表→自由侧强制取命中表（保住「至少一字中喜用」）。单名分支 :170 只读 side1.命中→单名恒 true。

枚举分派（:304-311 处；else 现状路径零改动）：
- 单名 → 一遍：组合 filter `s1===K`，side1=lockPool(zd, true)。
- 第一 → 一遍：`s1===K`，side1=lock。
- 第二 → 一遍：`s2===K`，side2=lock。
- 任一（无辈字）→ 两遍 union：p1(`s1===K`, lock@side1) ++ p2(`s2===K`, side1, lock@side2)。
  去重证明：p1∩p2 只可能是重字对（c1=c2=zd），已被 :186 同字 guard 双遍各自剔除，无需显式去重。
- **辈字共存坍缩**：辈字 Y 锁位 p——X=Y→整体 no-op（结果与仅辈字逐字节等）；X≠Y 且 位置∈{任一,异位}→单遍双锁（side[p]=lock(Y)、side[另一]=lock(X)、组合 filter 双笔画相等，按 p 镜像）。
  **陷阱（必须照做）**：双锁时 X 的 lock 必须 `计入命中=true`——:182-183 中若 side2 命中表为空 Map 会明明可行却零候选。
- 忌神交互维持现状（不豁免）：双名 :187 皆忌才剔；单名指定字即忌→0 候选由空态兜底。
- assemble 依据（:245 旁）：`指定字'X'含于名（任一|居首|居末）`。
- 已知可接受副作用（文档标注，非 bug）：统计.可行笔画组合 在两遍下 (K,K) 双计数；(K,K) 组合双遍各截 PAIRS_PER_COMBO=6（最多贡献 12 对）。

## 2. 好意向字库 src/data/good-intent-chars.json（新，char-data agent）

条目形状（ASCII key 可，全链一致即可；推荐与库内 mingren 风格一致）：

```ts
interface 好意向字 {
  字: string;            // 单汉字
  五行: '木' | '火' | '土' | '金' | '水';
  意向标签: [string, ...string[]]; // 1-3 个，每个 ≤6 字
  寓意: string;          // 4-20 字，一句话说清好在哪；不得伪造古籍引文
}
```

硬性要求 + tests/data/good-intent-chars.test.ts 校验（照抄 tests/mingren/data.test.ts 范式）：
- 规模 ≥300 条；字全局唯一。
- **CharDB 交叉核验（防死条目）**：`loadCharDB()` 后逐条断言 字∈db.字 且 五行与 db 一致 且 db 条目非多音——违者整测红。
- 常用级 ≥1（拒生僻）；五行五类各有覆盖（每类 ≥30）。
- 意向标签非空数组；寓意长度界内；不得含「皇家专用」「帝王」类不可考证溢美。
- 选字取向：像人名、寓意正向（明德、致远、沐恩一路），避爆款顶流字堆量（爆款权重高者可收但占比 ≤1/4）。

## 3. 抽卡（lib 禁 Math.random 纪律不破——随机只在 UI 层；draw agent）

### 3.1 src/utils/char-draw.ts（纯函数、注入式 rng，仿 SnapshotStorage 范式）

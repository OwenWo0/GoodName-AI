> 调研：research-tw-hk-culture，2026-08-29。WebSearch API 始终报错 400，全程改用 curl 直抓原始页面，所有引用来源均已实际验证可访问。

# 一、台湾

## 1. 姓名条例与户政规范
现行《姓名條例》（民国113年/2024年5月修正版）要点：
- **用字标准（第2条）**：取用姓名「應使用辭源、辭海、康熙等通用字典或教育部編訂之國語辭典中所列有之文字」；未列文字「不予登記」。2015（104）年修法把原本仅限《國語日報》《教育部重編國語辭典》两本字典，扩大为四部通用辞书，罕见字空间明显放宽。来源：https://zh.wikisource.org/wiki/姓名條例_(民國113年)
- **结构限制（第3条）**：姓前名后，姓名之间不得以空格或符号区隔；本名以一个为限（第1条）。
- **音韵登记字段**：一般民众户籍**不登录注音/拼音**；仅原住民族（族语文字并列）与归化外国人（罗马拼音并列）可例外（第4条）。即「读音」在台湾是民间自选事项，非法定字段。
- **改名门槛（第9条）**：因「字義粗俗不雅、音譯過長或有特殊原因」改名**以三次为限**——「改名改运」文化受法律次数管制。
- 内政部户政司专设「取用中文姓名專區」（https://www.ris.gov.tw/app/portal/349 ）提供命名用字参考，政府主动服务命名需求。
- 罕见字实务：非登载字无法登记，户政端以「造字」处理，造成台湾大量身份证造字族；产品必须能显示/描述造字（拆字查询）。

## 2. 命理命名文化普及度
- **五格剖象法**（康熙笔画+81数理判吉凶）源自20世纪初日本，战后回流台湾，1980年代后与「姓名学」一起爆发，至今是台湾命名市场主流话术；配合八字喜用神形成「先八字、后五格」的标准接单流程。
- **通书/择日文化**仍是大众媒介：台湾每年印制约五六百万本黄历通书，多自称承自福建「繼成堂」。来源：https://zh.wikipedia.org/wiki/通勝
- 命理名师高度媒体化（电视玄学节目、流年书年年出，代表人物横跨港台，如苏民峰）；「师傅命名」是成熟高价行业（数千至上万台币）。

## 3. 热门名趋势与「菜市場名」文化
- 台湾俗称大众名为「菜市場名」（菜市場喊一聲多人回頭），全民自嘲梗，直接影响父母避重名心理。
- 全台十大常见名（内政部2023年发布）：男「家豪」（14,038人）「志明」「建宏」「俊傑」…；女「淑芬」（31,879人）「淑惠」「美玲」「雅婷」…。
- 世代轮换：1960-70s「志X」→ 1980-90s「冠X」（冠宇/冠廷）→ 2000s「承X」（承恩/承翰）→ 2010s 新生儿「宥/品/睿」系（宥翔、品妍、品睿）与偶像剧风（宜蓁、欣妤、詩涵）。来源：https://zh.wikipedia.org/wiki/最常見名字列表 （引内政部/健保署统计）
- **注音与声调**：民间评名以国语四声为主，讲究三字声调错落（忌全平/全上连读变调拗口）、忌国语+闽南语双重谐音；注音符号是台湾人的读音心智模型（产品标音宜提供注音或拼音对照）。

## 4. 繁体中文产品要求
全繁体 UI 是底线；笔画一律以繁体字形的康熙笔画计；「著/着、裏/裡、台/臺」等按台湾教育部标准字形（国字）渲染；生僻名用「部首+笔画拆字查询」兜底。

# 二、香港

## 1. 八字/风水命名与玄学媒体
- 港式命名以**八字命理为尊**（先排四柱、定喜用，再配字形字音），五格笔划作辅助；「师傅改名」是成熟收费行业。
- 玄学媒体生态极发达：报纸命理专栏、流年运程书、电视玄学节目常年不断。代表人物苏民峰自1986年开班授徒，著作含《蘇民峰玄學錦囊(姓名篇)》《蘇民峰八字論命》，并有有线电视《「峰」生水起精讀班》等节目——「姓名」本身就是玄学畅销书独立品类。来源：https://zh.wikipedia.org/wiki/蘇民峰
- **通胜文化**：广东「崇道堂」罗传烈通书是香港流行源头；现时香港通书为私人印制，以蔡伯勵「真步堂」最著名（曾为1997回归选日而家喻户晓）。「通書」因「書」与「輸」粤音同音被忌，改称「通勝」——活生生的港式谐音改名案例。来源：https://zh.wikipedia.org/wiki/通勝

## 2. 粤语读音：九声六调与谐音忌讳
- 标准粤语有 **9 个声调、6-7 个固定调值**，其中 3 个入声（阴入/中入/阳入，-p/-t/-k 韵尾收尾短促），如「分fan1 焚fan4 粉fan2 奮fan5 份fan6 訓fan3 忽fat1 發faat3 佛fat6」。来源：https://zh.wikipedia.org/wiki/粵語 （聲調系統节）
- **平仄体系错位**：「平仄」本依中古音平上去入；以普通话「一二声=平」近似者，与以粤语「阴平/阳平=平」判断者，同一姓名归类可能完全不同，且入声字在两读中归派不一。平仄计算必须先定调系。
- **谐音检查必须双语跑**：
  - 官话忌讳、粤语安全：「詩琴」普通话 shīqín≈「失錢」shīqián（大忌），但粤语 si1 kam4 与 sat1 cin2 音距甚远，无碍——团队引用的经典反面案例恰是普通话体系的。
  - 粤语独有、普通话无感：粤拼 ng- 自成音节使「吳」读如「唔（不）」，如「吳德」粤读 ng4 dak1≈「唔得」（粤语＝不行/无望），普通话 wú dé 则无此联想（此为据粤拼规则构造的机制示例）。
  - 文化级案例：「通書→通勝」避「輸」；车牌/电话风水同理。
- 港人命名第一怕粤音谐音（尤其粗口同音），第二才看笔画八字——普通话评「雅」、粤语评「吉利」是两套标准。

## 3. 英文名文化与港式热门名
- 港人普遍「洋名＋中文名」双名制：洋名多源于圣经/西方人物（米高、约瑟、伊丽莎白），且**音译按粤拼**（来源：https://zh.wikipedia.org/wiki/洋名 ）。同一外国名两区译法不同：Beckham 普通话「贝克汉姆」粤语「碧咸」、Reagan 普通话「里根」粤语「列根」——若做「中英名配对」功能，港版必须走粤拼音系与港台通用译名表。
- 港式中文名风格：单字英文潮名（Him、Ching 类）与「皓/睿/彤/希」类中文字并行。**注意：港府不公开新生儿名排行，此节缺官方数据，属待补缺口**（建议接媒体大数据稿）。

## 4. 数字吉凶心智
- 粤语「28」(ji6 baat3) 谐音「易發」，是车牌、电话、单位号的顶流吉数文化（普通话区无此联想）；8（發）全民通吃、4（死）普通话区忌讳。来源：https://en.wikipedia.org/wiki/Chinese_numerology
- 港台用户对「数字本身有吉凶」深信不疑——五格 81 数理畅销正是这一心智在姓名上的投影。输出「数理吉数」对港台用户是刚需而非噱头。

# 三、对本产品设计的启示（8条）

1. **简繁转换**：全链路以**繁体为内部规范形**，简体输入先转繁再算笔画；转换器须处理一简对多繁（发/髮/發、后/後、里/裡），按词组而非逐字转（OpenCC 类词级转换），否则笔画直接算错。
2. **康熙笔画为唯一笔画标准**：统一繁体字形+部首归本形规则（艹(艸)6、氵(水)4、辶(辵)7、王(玉)5、阝(邑/阜)8 等），简繁共用同一张康熙字典笔画表；UI 标注「康熙笔画：N（本字 X 画）」建立信任。
3. **双读音双数据**：字库每字同时存普通话拼音与粤拼（jyutping）；谐音忌讳词典**分开两套**（官话库/粤语库，粤语库须含粗口同音）；警示语标注地区标签（如「此名粤语谐音不宜」），避免对另一区用户误报。
4. **平仄显式选系**：平仄引擎做成三模式——普通话（一二声为平）、粤语（阴平/阳平为平、入声单列标记）、中古音（平上去入，适配诗词派）；结果页明示所用体系，不默认单一。
5. **用字合规提示**：内置台湾《姓名條例》第2条四部辞书（辭源/辭海/康熙字典/國語辭典）联合字表，每个推荐字附「台湾可登记 ✓／造字风险 ⚠」标签；生僻字输入提供部首+笔画拆字查询与图片兜底。
6. **注音/粤拼展示**：台湾版名字标注音符号（用户心智模型），港版标粤拼+九调数字，大陆版标拼音+四声——同一数据三套渲染。
7. **数理吉数默认展示但口径固定**：港台版默认呈现五格数理与吉凶数（契合 28/8 文化心智），但由确定性算法输出、可复现可追溯；AI 综合文案统一「民俗说法」口吻，规避保证式措辞（台湾改名法定三次的限制可作免责背书）。
8. **港版双语与译名**：UI 支持中英双语（洋名文化），英文名配对/回译走粤拼音系；建立港台通用译名对照（碧咸/贝克汉姆类），并预留港式热门名数据源（官方排行缺失，需媒体数据补充）。

# 固定算法与开源选型调研报告

> 调研：research-algo-libs，2026-08-29。npm 版本均已核实；lunar.js 结论来自直接解析源码逐方法验证。

## 模块① 八字排盘 —— 推荐 lunar-typescript + 自研真太阳时

已核实 npm：lunar-javascript 1.7.7（2025-11）、lunar-typescript 1.8.6（2025-11，TS 版同代码源）、tyme4ts 1.5.2（2026-06）均活跃维护；cnlunar/sxtwl 不在 npm（sxtwl 是 C++，无官方 wasm）。

直接解析 lunar.js 源码确认 EightChar API 全存在：四柱 getYear/Month/Day/Time、十神 getYearShiShenGan/Zhi 等（日主=getDayGan）、藏干 getXHideGan、纳音 getXNaYin+胎元命宫身宫纳音、逐字五行 getXWuXing（**五行力量统计需自己聚合**）、十二长生 getXDiShi（得地判断）、旬空、getYun(gender,sect)→getDaYun(n)/getLiuNian/getXiaoYun/isForward、setSect(1|2) 晚子时日柱开关。节气分月内置（寿星天文历，节气精确到秒）。覆盖固定算法需求约 95%。

已知坑：
1. **真太阳时全库 0 支持**（grep「真太阳/均时差/经度」0 hits）。自研公式：校正=4×(出生地经度−120°)+均时差EoT，在 Solar.fromYmdHms 之前应用；临界风险=时辰交界±1h、节气交接前后、23-24点。
2. 晚子时 23 点流派争议：lunar setSect / tyme4ts LunarSect1/2EightCharProvider，建议 UI 让用户选或双盘并列。大运起运也有 sect（按日/按时辰）。
3. 中国 1986-1991 历史夏令时，库不处理，表单加勾选。
4. tyme4ts 能力等价（HeavenStem.getTenStar、SixtyCycle.getSound、ChildLimit→Fortune 大运）但 API 更抽象；建议作第二引擎做双跑回归，不一致报警。

## 模块② 五格剖象 —— 数据用 shunshi-kangxi-core，计算自研

康熙笔画数据集候选（已核实）：
- **shunshi-kangxi-core 0.1.1**（npm, 2026-08-15, MIT）：零依赖 TS，解包 4.2MB，20,794 康熙字典正字，同时含简体/繁体/康熙三套笔画+部首+五行+拼音，README 明确处理 氵=4/艹=6/忄=4/万=15 特例。首选，但发布仅 2 周需抽样校验。
- Unicode Unihan（kTotalStrokes+部首索引）：权威原始数据备选。
- GoodGoodName（★421, data/full_wuxing_dict.py, 五行→笔画→字表）与 peiss/chinese-name-score（★311, sancai.txt 33KB 三才配置表）：交叉校验+数据转录源。

部首特例校验清单（可直接测 GoodGoodName 已知 bug）：辶=辵7、氵=水4、王=玉5、艹=艸6、阝左=阜8/右=邑7、忄=心4、犭=犬4、礻=示5、衤=衣6、肉月=6；簡繁一對多：万→萬15、与→與14、学→學16、丑→醜17。**最大坑：查笔画前未先做簡→繁转换**；另需未收字（新造字/和制汉字）fallback。

81 数理/三才：无现成 TS 包但是静态表，从 GoodGoodName sancai.txt/peiss 转录清洗成自有 JSON（半天工作量）；规则：数理>81 减 80 循环。

五格算法要点（自研~100行）：天格=单姓姓+1/复姓两字和；人格=姓末+名首；地格=单名名+1/名两字和；总格=全和；外格=总格−人格+1（单姓单名=2）；三才取天人地个位（1,2木3,4火5,6土7,8金9,0水）查125条配置表。坑：复姓单名外格、笔画必须全康熙数。shunshi-naming-core 0.1.0 有整包五格引擎（依赖 kangxi-core），太新，建议只取数据层。

## 模块③ 平仄 —— pinyin-pro 单库即可

（注：此模块中途曾被移出重点，验证深度不及①②，API 细节按 README+已知接口形态描述）
- **pinyin-pro 3.29.3**（2026-08-19，活跃维护，已核实 npm）：`pinyin(str, { toneType: 'digit'|'symbol'|'none', type: 'array' })` 逐字取调；`polyphonic: true` 返回多音字全部读音；`mode: 'surname'` 姓氏特殊读音（解"单shàn/曾zēng/查zhā"，起名场景必开）；`converter()` 词组级上下文消歧。普通话平仄判定本身：1/2声=平、3/4声=仄（入声在普通话已消亡，按今音即可；若要古韵平仄需《平水韵》数据，目前无现成 npm 包）。
- 已知坑：① 人名多音字读音常"约定俗成"非词典读音（乐 lè/yuè、熙/晗等生僻字），polyphonic 多读要全部透出给用户/AI 综合层；② surname 模式覆盖不全，生僻姓氏仍会错。
- 粤语平仄：最佳候选 **to-jyutping 3.1.1**（2024-09，基于 OpenCC 粤数据，已核实 npm）；旧包 yuepin 1.0.1（2023）、sam1lam4（2017）太旧不推荐。粤拼声调 1-6，通行处理：平=1/4（阴平阴去），仄=2/3/5/6（上声+全入声归仄）。建议放 v2 加分项。

## 模块④ 喜用神 —— 无成熟 TS 库，全自研，Python 开源取规则

已核实：**没有任何维护中的 npm 包提供喜用神判定**。cantian-ai/bazi-mcp（★425, TS）只有排盘输出、无喜用神。规则参考（Python，取规则不取码）：china-testing/bazi ★1488（旺衰/用神规则文档最细）、jinchenma94/bazi-skill ★2823（规则文字化程度高，适合转译）、qianye-wuyu/yueyuan-bazi ★217（从格状态机思路）、JakLiao/GoodGoodName ★421（含喜用打分但有已知 bug，仅参考）。

自研方案（输出打分+依据链，供 AI 综合层引用）：
1) 日主强弱打分：得令（月支主气，藏干按主气40/中气20/余气10 加权）+ 得地（其余三支根气，lunar 的 getXHideGan/getXDiShi 正好当输入）+ 得势（天干帮扶数），输出各五行力量数值表；
2) 扶抑：强→取克泄耗、弱→取生扶；从强/从弱边界阈值必须透出，别黑箱；
3) 调候：《穷通宝鉴》10天干×12月支用神静态表，需人工整理成 JSON（1天）。

工作量估计：核心打分 1-2 天 + 调候表 1 天 + 与 lunar 大运联测 1 天。**扶抑与调候结论冲突时必须显式化为结构化字段**（如 `{扶抑:{...}, 调候:{...}, 冲突:true}`），正好喂 AI 综合层。

## 模块⑤ 字五行字典 —— 随康熙笔画数据集一起拿，别单找

- **shunshi-kangxi-core 0.1.1** 每字自带五行归属（首选，与康熙笔画同源，保证笔画/五行一致）；
- GoodGoodName `data/full_wuxing_dict.py`（53KB，按五行→笔画→字表组织的姓名学字表，来源未验证，交叉校验用）；
- ben-hua/general_standard_chinese ★27（通用字表附带拼音+笔画+部首+五行，仅交叉参考）。

坑：字的五行有多套体系——字形部首归属、康熙笔画尾数数理五行（1,2木3,4火5,6土7,8金9,0水）、音韵五行，三者结论常冲突。**固定算法层建议只用"字形五行"一种并在 UI 标注体系名**；笔画数理五行归五格模块单独输出，不混算。

## 模块⑥ 简繁转换 —— opencc-js，无悬念

**opencc-js 1.4.2**（2026-08-22，MIT，已核实包内含全套 ST/TS/TW/HK 词典共 57 文件，纯 JS 离线、浏览器/node 通用）。API：`OpenCC.Converter({from:'cn',to:'tw'})`。常用字表：shengdoushi/common-standard-chinese-characters-table ★125（《通用规范汉字表》8105 字纯数据，vendored 成 JSON）。

坑：① 一对多转换方向性（后→後、发→髮/發、面→麵）——管线固定为 **简体输入 → cn2t → 康熙笔画查询**，tw→cn 不可逆、展示层别来回转；② 姓名用字可能是词组规则改写不到的单字，失败时 fallback 按字头直查 kangxi-core；③ 港澳台异体用 TWVariants/HKVariants 配置项。

## 全局坑汇总（测试点清单）

1. **真太阳时**：校正后时辰/日柱/节气分月三处都可能翻盘（高危窗口：23-24点、0-1点、节气交接前后）；库 0 支持，自研模块必须有单测。
2. **晚子时 23 点流派**：lunar setSect(1|2)、tyme4ts Sect1/2Provider——UI 让用户选或双盘并列，AI 提示差异。
3. **1986–1991 中国夏令时**出生者：墙上时间需回拨 1h，库不处理，表单加勾选。
4. **康熙笔画三类必测**（GoodGoodName 已知 bug 排查清单）：部首特例（辶7/氵4/王5/艹6/阝左8右7/忄4/犭4/礻5/衤6/肉月6）、简体未转繁直接计数（万应=15）、康熙字典未收字 fallback 行为。
5. 五格边界：复姓天格=两字和、单名地格/外格+1、单姓单名外格=2。
6. 字五行体系冲突：固定层只用字形五行并标注体系。
7. 喜用神扶抑 vs 调候冲突：显式输出字段，不黑箱。
8. 排盘双引擎回归：lunar vs tyme4ts 跑 100 个含 23 点/节气交界/真太阳时临界生日做一致性对比。

## 0. 实探结论（一句话）

**免登录即可拿到完整确定性排盘表**（四柱、刑冲合会、五行雷达、十神、神煞、大运、起运、流年~11岁、流月2026）。点击「开始 AI 分析」弹**登录墙**（"登录或注册账号以使用完整功能"）。可见输出里**没有**格局、喜用神、调候、纳音、身强身弱——这些要么走 AI（需登录）、要么不在免费盘里呈现。它的付费墙主要卡在「AI 深度解读 / 未来流年 / 流月 / 合盘」，而非基础排盘。

> 对我方的意义：竞品把「算法可信度」当营销卖点公开（版本号 v30、86 个时间测试、57 神煞 100% 召回、典籍出处），但把**结论性内容（格局/用神）藏进 AI 与订阅**。我们「固定算法 + 透明双轨 + 一句裁决」正是打这个含糊点的差异化。

### 2A. 竞品有、我方无 → 是否补
- **必须正视**：`时辰未知`、`农历/闰月切换`、`真太阳时开关`——**输入体验缺口，v1 补**（否则流失只知农历/时辰的用户）。
- **展示可抄（不动契约或仅加可选字段）**：起运精确到小时的措辞、五行"同我/我生…"关系标签、雷达图、十神藏干权重(1.0/0.7/0.5)与断语、大运每步特征句。→ **v1 展示层**。
- **氛围增强（v2）**：神煞、刑冲合会、流年流月。竞品把格局/用神藏进 AI，我方反而**透明展示喜用神(扶抑+调候+冲突)**——这是打它含糊卖点的点，别丢。

### 2B. 我方有、竞品无 → 差异化保留
- **纳音**（竞品免登录盘里没有）、**喜用神双轨(扶抑/调候/冲突显式)**、**五格剖象(天人地外总+81数理+三才+起源争议标注)**、**平仄/谐音/绕口**、**通用规范汉字表落户校验**、**爆款字/重名降权**、**辈字/避讳**、**诗词寓意候选名**。全部保留——这些是"起名"赛道本体，竞品根本不碰。
- 我方 `五行力量带来源链`、`真太阳时校正量显式`、`晚子时流派标注`、`双引擎一致性` 比竞品更透明可核对——正好对标它"经得起核对"的营销主张，且我方**免费全公开**而它把结论藏订阅。

### 2C. 同有但对方展示更好 → 值得抄
1. **起运时间**："出生X年X个月X天X小时后起运" + 确切日期时刻——比裸"起于周岁"直观。**抄文案**。
2. **校正三行拆解**：输入时间 / 标准经线 / 真太阳时修正(带±分钟) 分行呈现，可信度强。**抄结构**。
3. **五行关系标签**（同我/我生/我克/克我/生我）+ 雷达图：比裸分数好读。我方保留加权分但**叠关系标签**。
4. **十神藏干权重内联 + 每柱断语 + 分布汇总**：把抽象十神变人话。**抄模板**（文案入数据表）。
5. **折叠/分层**：每块用"标题 + 一句总述 + 明细 + 免责尾注"的卡片节奏，长而不乱。**抄节奏**。
6. **边界不确定性主动提示**（见 §4）：把"命盘根基扎不扎实"讲透，反而增信。**抄理念**——直接补强我方文案。

## 4. 免责 / 不确定性措辞观察（供我方文案参考）

竞品实测原句：

- 营销尾注：`*本服务基于传统命理学，仅供参考娱乐，重要决策建议综合多方因素考虑`
- 结果尾注：`本服务仅供娱乐之用。重要决策应结合个人认知积累、生活经历及专业建议综合考虑。`
- 神煞块首：`神煞仅作辅助参考，不宜单独论吉凶。`
- 五行块：`数量分布仅供参考，需结合日主关系来理解。`
- FAQ 谈准确性：`虽然没有任何系统能够确定地预测未来，但八字能为性格特征、潜在挑战和有利时机提供有价值的参考。`
- **不确定性专章**（值得重点借鉴）标题：`命盘卡在边界上时，我们会告诉你` —— 正文列举四类边界：①出生时间距时辰交界仅差几分钟 ②真太阳时修正后跨入另一时辰 ③出生日期落在夏令时窗口 ④晚子时两口径排出不同盘；结论句"排盘器会明确提醒并展示差异，而不是把其中一种可能当作定论呈现。一张值得信任的命盘，从知道它的根基有多扎实开始。"

**我方落地建议**：
1. 保留我方"民俗说法/传统文化参考，非科学结论"的基调（比竞品"仅供娱乐"更正经、不自我矮化），但在**具体结论处**模仿竞品的**局部限定语**（如神煞"仅作参考"、五行"需结合日主"）——把不确定性下沉到每个模块，而非只在页脚挂一句。
2. **直接采纳"边界主动提示"理念**：我方已有 `真太阳时校正`、`晚子时流派`、时辰未知降级——正好可实现同款"命盘根基提示"卡：当校正后跨时辰/跨日、晚子时双口径、时辰未知时，明确亮差异，不假装确定。这对起名"祖辈会拿另一盘来质疑"的决策链尤其有用。
3. 权威感来源抄竞品的"典籍出处 + 可核对工程"（渊海子平/三命通会/子平真诠/滴天髓/穷通宝鉴 + 版本号 + 测试数），我方用 `双引擎一致性`、`争议标注`、`五行力量来源链` 兑现"可核对"，且**免费全公开**，反打它"藏进订阅"。

## 5. 未验证 / 存疑项（不臆造）

- **格局、喜用神、调候是否在其免费盘某处渲染**：实测 `innerText` 中"格局/从格/专旺/化气/调候/纳音/身强身弱"仅出现在**页脚导航、指南链接与营销介绍**里，**计算结果区未见**其作为排盘字段渲染。结论：这些**不在免登录确定性输出表内**；是否登录后/AI 解读中出现，因登录墙未验证。
- **AI 深度分析、正缘、未来流年/流月**：均为登录墙/订阅墙后，未进入，不描述其内部字段。
- 出生地经纬度、农历闰月切换的实际行为未逐一提交验证（避免误改默认盘），仅据表单标签推断。

## 1. 总体架构

```

├── src/
│   ├── lib/                      # 固定算法引擎（纯函数、零 IO、全单测）

│   ├── data/                     # vendored 静态表 JSON（81数理/三才/调候/谐音黑名单/爆款字/字表）

│   │   └── api/
│   │       ├── chart/route.ts    # POST：算法引擎全量输出（无 AI，纯 JSON）
```

**铁律**：`src/lib/**` 不得 import next/react；AI 层只消费 `ChartResult` 结构化 JSON；Qwen key 仅 `server-only` 模块读取 `process.env`。

## 2. 数据契约（AI 输入 = /api/chart 输出）

```ts
interface ChartResult {
  bazi: { 四柱, 十神, 藏干, 纳音, 五行力量表, 大运, 真太阳时校正量, 晚子时流派, 双引擎一致性 }
  wuge: { 天人地外总(数理+吉凶), 三才, 康熙笔画明细, 争议标注 }
  xiyongshen: { 强弱得分, 扶抑:{五行[]}, 调候:{五行[]}, 冲突:boolean }
  pingze: { 逐字平仄, 声调, 拼音(含多读), 体系:'putonghua' }
  candidates: { 名, 五行, 平仄, 五格, 谐音检查, 字表校验, 爆款度 }[]   // 算法海选池
}
```

## 3. AI 层（`api/analyze`）
- `openai` SDK：`baseURL: https://pipe.intelli-go.cn/v1`，`model: qwen3.8-27b`，key=`process.env.LLM_API_KEY`（`.env`，gitignore）。
- SSE 转发：`delta.reasoning_content` → 事件 `reasoning`（UI"命理师推演中…"）；`delta.content` → 事件 `delta`。
- System prompt 要点：民俗说法口吻、禁止保证式措辞、引用算法依据链、从候选池挑选并写故事卡（诗词出处+白话寓意）、输出 JSON 块（最终推荐 Top-N 索引）供前端渲染卡片。

## 5. 风险与对策
- shunshi-kangxi-core 发布仅 2 周 → M1 抽样校验（部首特例清单）不过则切 Unihan kTotalStrokes。
- Qwen 端点为第三方代理 → AI 层超时/失败时 UI 降级为"仅算法报告"，不阻塞主流程。
- 真太阳时 EoT 精度 → 用标准近似公式（误差<30s），单测对齐已知日期均时差表。
- 中文 webfont 体积 → 首版 Google Fonts(Noto Serif SC/Ma Shan Zheng) + 文楷 jsDelivr，子集化列入 v2。

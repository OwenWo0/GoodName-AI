# 尽调总报告与产品定义

> 汇总自 4 份分报告（`docs/research/01~04`），2026-08-29。
> 产品定位：**古风中文起名网页**——固定算法排盘（八字/五格/喜用神/平仄，零 AI、确定性、可测试）+ AI 综合分析（Qwen，仅做汇总解读与候选名推荐）。

---

## 一、市场与文化结论（一页速览）

1. **两大方法论并存且互怼**：正统派看八字喜用神（"缺≠补"），流行派看五格剖象（日本熊崎氏 1920s 产物、传统命理界不认可）。工具必须**双轨呈现、各自标注适用范围**，冲突时透明分层给结论——竞品全都含糊其辞，这是差异化点。
2. **用户真实排序**：好听好读不撞梗 > 寓意出处 > 八字五行 > 五格分数 > 重名率。竞品把结论埋在数据山后面；我们**先一句话裁决，细节折叠**。
3. **重名焦虑是刚需**：公安部年度姓名报告、爆款名（奕辰/一诺/沐宸/若汐）、"菜市場名"文化——候选名必须带**重名率 + 爆款字警告**。
4. **谐音是第一红线**，且官话/粤语两套结论不同（詩琴普通话犯忌、粤语无碍；吳德粤语犯忌）。v1 至少普通话谐音库，粤语库视范围决策。
5. **政策硬约束**：大陆《通用规范汉字表》8105 字外无法落户（硬校验+警告）；台湾《姓名條例》四辞书外用字不予登记（v2 标签）。
6. **决策链**：妈妈主导、祖辈有否决权（辈字/避讳）→ 输入项必须有**辈字锁定、避讳字**；确认前推翻 3+ 次是常态 → **无限生成+收藏+对比**，不做一次性"最终答案"。
7. **合规基调**：命理内容标注"传统文化参考/民俗说法，非科学结论"，文案权威感来自数据与典籍而非神断语气。
8. **美学即差异化**：全行业 UI 是 2010 门户风。锚定"宋画留白+细线+矿物低饱和+朱不过三"，字体全 OFL（Noto Serif SC / 霞鹜文楷 / 马善政），方正零使用。

## 二、产品定义（v1）

### 输入（zod 校验）
- 必要：姓氏（简/繁）、性别、出生日期+时辰（可"未知"降级）、名字形式（单/双/父姓+母姓四字）
- 增强：出生地（经度→真太阳时）、夏令时勾选（1986–1991）、晚子时流派选择、定字/辈字、避讳字列表、寓意愿望（自由文本+标签）、诗词典籍偏好、当地方言背景（谐音检查用）

### 输出五模块（对应五大目标）
| # | 模块 | 引擎 | 要点 |
|---|---|---|---|
| 1 | 八字排盘 | lunar-typescript + 自研真太阳时 | 四柱/十神/藏干/纳音/大运/五行力量表；真太阳时校正须在进库前；tyme4ts 测试期双跑 |
| 2 | 五格剖象 | 自研 + 康熙笔画数据 | 天/人/地/外/总+81数理+三才；页内标注起源争议；笔画管线：简体→cn2t→康熙表 |
| 3 | 喜用神 | 全自研 | 强弱打分(得令/得地/得势)+扶抑+调候(穷通宝鉴表)；冲突显式化 `{扶抑,调候,冲突}` |
| 4 | 平仄分析 | pinyin-pro | mode:'surname'+polyphonic；v1 普通话系，架构留三模式接口（粤/中古音 v2） |
| 5 | AI 综合分析 | Qwen（OpenAI 兼容） | 输入=上述四模块结构化 JSON；输出=一句话裁决+综合解读+候选名推荐；流式双流（reasoning_content→"推演中"，content→正文） |

### 候选名硬过滤（固定算法层，AI 输出后仍需过一遍）
通用规范汉字表校验 → 避讳字排除 → 辈字/定字锁定 → 谐音黑名单 → 爆款字降权 → 喜用神五行匹配（字形五行体系）→ 五格吉凶（展示权重，非硬过滤）。

### 非目标（v1 明确不做）
注册/付费体系、公司起名、英文名配对、拆字查询、吴语/闽南语谐音、真太阳时地图交互彩蛋（留 CSS 占位）。

## 三、技术架构（草案，详见 `docs/架构与实施计划.md`）

- **全栈 TypeScript**：固定算法全部跑在服务端/本地纯函数模块，AI key 必须服务端持有 → 需 server 端（框架选型待拍板）。
- **算法层**：纯函数、零 IO、每模块一文件+单测；数据表 vendored JSON。
- **AI 层**：`openai` SDK `baseURL=https://pipe.intelli-go.cn/v1`，`model=qwen3.8-27b`，key 走 `.env`（gitignore），`.env.example` 占位；SSE 流式转发，`delta.reasoning_content`/`delta.content` 双通道。
- **UI**：古风设计令牌（墨 #2b2b2b/宣纸 #f6f1e7/朱砂 #9e2b25/黛蓝 #34495e/鎏金 #b08d57；五行矿物色）；手卷式结果流：排盘→五行→五格→平仄→吉名→跋(AI综评)。

## 四、已锁定决策
1. LLM = 用户提供的 Qwen OpenAI 兼容端点（models/chat/streaming 已 curl 冒烟验证通过）；API key 只进 `.env`。
2. 固定算法零 AI 介入；AI 只吃结构化算法输出。
3. 数据选型按 `docs/research/03` 技术栈清单执行，shunshi-kangxi-core 先抽样校验再 lock。

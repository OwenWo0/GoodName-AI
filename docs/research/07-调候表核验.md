## 1. 来源

| 角色 | 来源 | 用途 |
|---|---|---|
| 主源 | Wikisource《窮通宝鑑》（zh.wikisource.org/wiki/窮通宝鑑） | 逐章逐月手工校订，唯一裁定依据 |
| 比对源 A | renchou/vue-bazi 调候速查表 | 仅作分歧提示 |

三个比对源为「简化速查表」性质，实测互不一致且各有讹误（见 §4 庚未例），故一律以原文裁定。抓取过程全程仅做正则解析，不执行外部仓库任何代码。

## 2. 收录口径（校订规则）

1. 取每章（各干 × 各月）开篇总则句中标举的用神，**严格依原文次第**（排盘下游按序取用，不得排序）。
2. 标举即收：含「酌用」「佐之」「加-X」等辅助用神；**不收**「或 / 若 / 倘」条件句与忌神（如庚未之癸）。
3. 天干→五行映射：甲乙=木、丙丁=火、戊己=土、庚辛=金、壬癸=水；格内去重（保首次出现序）。
4. 每格附「依据」原文摘句，可逐格回溯；`_meta.校勘记` 记录全部通例与逐格分歧。

## 3. 硬锚点（与 `tests/xiyong/tiaohou.test.ts` 所钉一致）

甲子=火金、乙寅=火水、丙午=水、丁未=木水、戊午=水木火、己巳=水火金、庚辰=木火、辛亥=水火、壬申=土火、癸酉=金火、壬丑=火木。

## 4. 代表性校订取舍（全文 27 条见 JSON `_meta.校勘记`）

- **庚未（比对源集体致误的典型）**：三源皆作「水木」，然原文「先用丁火，次取甲木，**忌癸伤丁**」——水为忌神被误收。从原文 → 火木。此例确立「原文为权威、简化表仅为提示」的总原则。
- **丁申/丁酉**：依「三秋甲庚丙并用：七月甲丙（申中藏庚），八月甲丙庚皆用」→ 木火金。
- **丁亥/子/丑**：「甲木为尊，庚金佐之」→ 木金；「癸戊权宜酌用」系权宜之语，不取。
- **辛寅**：「先己后壬，己为君，庚为佐」→ 土水金（「用丙须参看」为参看语，不取）。
- **戊戌**：「先看甲木，次取癸水」→ 木水（丙仅见于「见金」条件句，不取）。
- **甲辰**：原文「先庚后壬」→ 金水；部分简化表序作「水金」，从原文次第。
- **乙丑**：Wikisource 原文阙「十二月乙木」条，唯一以共识定值（丙先癸次 → 火水），「依据」中注明阙文，测试亦断言含「阙」字。
- **仅标举一字而从原文者**：丙卯（耑用壬水→水）、丙午（三源皆作水金，原文无庚→水）、己寅（丙为尊→火）、癸未（专用庚辛→金）等。
